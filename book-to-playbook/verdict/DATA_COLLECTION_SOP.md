# 구간③ 데이터 수집 표준절차 (SOP) — 어떤 책이 와도 이렇게 처리한다

이 문서는 **새 책이 들어올 때 구간③(판정) 데이터 수집을 어떻게 진행하는가**를 못박는다.
목표: **사람의 개입을 최소로, 저자의 의도대로, 창작·누락 없이, 완주.**

## 대원칙

> 저자가 시킨 것을 **그대로** 수집한다. 코드가 기준을 몰래 정하지 않는다.
> 구할 수 있는 데이터는 **반드시 수집**한다. 진짜 없을 때만 ✋직접.
> "잘 모르겠으니 직접" 은 금지 — 그건 사람 병목이다.

## 계산기 하나를 붙일 때 (author 조건 → metric)

1. **저자 조건을 정량 축으로 분해한다.** 기준선·기간·대상·문턱. (예: "거래량 전일 1.5배" → 기준=전일, 문턱=1.5)
2. **계산기가 자기 의미를 선언한다** (`metric_registry.json`). 코드에 기준을 숨기지 않는다:
   - `computes` : 무엇을 계산하는가 (한 줄)
   - `label`    : 화면 라벨 템플릿 (손으로 라벨 쓰지 않는다 — 여기서 파생)
   - `ground`   : 계산 기준의 근거 토큰. 고정 축이면 `any`, 규칙이 정하는 축이면 `param`/`by`+`axes`
   - `incomplete`: 이 계산기가 **확인 못 하는** 저자 조건(있으면)
   - `supersede`: 더 완전한 대체 계산기가 있으면 (누락 시 자동 교체 대상)
3. **선택 축은 규칙이 값을 채운다** (예: `baseline: prev|ma20`, `ma: 20|60`). 계산기는 그 값을 읽어 계산·라벨을 파생한다 → **선언과 계산이 한 몸이라 어긋날 수 없다.**

## "데이터를 구할 수 있는가" 판단 — 에이전트가 직접 조사한다 (사람에게 안 묻는다)

순서대로 조사한다. **못 구한다고 단정하기 전에 아래를 다 뒤진다:**

1. **시세 창구가 이미 주는가** — `md_feed`(=jhts.marketdata) 필드 확인. `daily_features` 키(vol/vol20/ma/closes/…), `candles`(OHLCV 이력), `quote`, `minute_closes`.
   - 예: 전일 거래량은 `daily_features`엔 없지만 `candles[-2].volume`로 **구해진다** → 창구 함수 하나 추가(`md_feed.prev_volume`)해서 수집. ✋ 아님.
2. **파생으로 계산되는가** — 창구의 원자료(candles·closes 등)로 계산 가능한가.
3. **무료 외부 소스에 있는가** — 야후 EOD(OHLCV)·지수·선물 등. 있으면 창구에 필드를 추가하는 **일회성 구현**(🚧), ✋ 아님. (필요하면 웹을 뒤져 소스 존재를 확인한다.)
4. **정말 어디에도 없는가** — 뉴스 온도·애널리스트 추정·한국 수급·정성 판단 등 (`no_data_types`). **그제서야 ✋직접.**

판단 결과는 `metric_registry.json` 의 `auto_types`(구할 수 있음) / `no_data_types`(없음)로 박힌다.

## 어긋남 자동 해소 사다리 (사람 0 — `verify_metric_semantics.resolve_inplace`)

판정 직전(`verdict_engine.render`)에 자동 실행. 검증 안 된 계산기를 **틀린 값 대신** 안전한 쪽으로:

| 단 | 조건 | 조치 | 결과 |
|----|------|------|------|
| 1 | 저자 요구를 이미 계산하는 대체 계산기 있음(`supersede`) | 자동 교체 | 🤖 |
| 2 | 데이터는 구할 수 있는데 아직 못 맞춤 | 격리(틀린 값 차단) + 구현 과제 | 🚧 |
| — | 데이터 자체가 없음 | 규칙 authoring 때 이미 `source:manual` | ✋ |

## 검사(창작·누락) — `verify_metric_semantics`

`저자 소절 ⟷ 계산기 선언` 양방향 대조. **창작**(근거 없는 기준)과 **누락**(빠진 조건)을 한 검사로 잡는다.
발행 게이트(`run.py`)에서 돈다 — 어긋남은 **경고**로 뜨고 런타임 사다리가 안전 처리하므로 발행을 막지 않는다.

## 한계 (정직)

순수 정성 조건("힘있게 상승")은 기계가 못 못박는다 → **✋직접, 그리고 그렇게 표시**. 자동인 척 위장 금지.
목표는 "틀릴 수 없다"가 아니라 **"틀리면서 조용할 수는 없다"** — 그리고 구할 수 있는 건 다 구한다.

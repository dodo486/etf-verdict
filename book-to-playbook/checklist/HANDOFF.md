## 확정된 원칙 8개 (EXTRACTOR.md 에 아직 반영 안 됨 — 다음 할 일 1)

| # | 원칙 | 내용 |
|---|---|---|
| 1 | 이해 | 저자가 시키는 행동을 **이 책대로 매매하려는 트레이더**가 이해하는 그대로 옮긴다. 시장 용어는 통상 뜻. 판단 문장은 **앞뒤 문단과 같이** 읽는다(행동이 다음 문단에 나올 수 있다). 금지는 원문에 없는 내용을 더하는 것뿐 — 트레이더 상식은 뜻 이해에만, 기준 숫자를 채우는 데는 안 쓴다 |
| 2 | 의도 | 칸은 행동의 의도로: **조건 하나 → 행동 하나 → 칸 하나**. 쉬게 함 = filter · 매수를 멈추게 함(조심·경계 포함) = avoid · 사라 = entry · 사되 줄임 = caution · 얼마나/나눠서 = sizing · 팔라 = exit. 조건이 다른 행동 둘이면 칸 둘. 같은 조건에 행동의 범위("쉬거나 아주 작게")면 **가장 보수적인 하나**(filter > avoid > caution > entry), 나머지는 note. **플레이북의 분류 꼬리표("필터:", "판정:")는 요약자의 것 — 무시하고 저자의 행동으로 정한다** |
| 3 | 빈칸 | 구조는 살리고 모르는 것만 비운다 — 숫자·기간·개수 `"?"`, 폭·비중·분할·**매도 비율** `"?"`/`null`. 빈칸 때문에 구조(점수표·모드·세 겹 손실선)를 버리지 않는다 |
| 4 | 예시 | 예시는 저자가 **가정으로 든** 숫자뿐("예를 들어"). 저자 본인의 배분·기준은 규칙, 금액 → % 는 계산(옛 "금액 예시를 비중으로 바꾸지 않는다" 삭제) |
| 5 | 한 대상 한 기준 | 같은 측정은 소절이 달라도 부품 하나. 다른 소절에서 저자가 그 측정의 숫자를 줬으면 그 숫자를 쓰고 ref 둘 다 |
| 6 | 운영 판단 분리 | 저자가 안 정한 구현 선택(섹터·대표주 티커)은 추출자가 고르지 않는다 — 이름 심볼(`$금융` 등)로 쓰고 실제 티커는 책 설정 한 곳에서(사용자 확인) |
| 7 | 자유도 0 | 형식은 문법이 정하고 코드가 강제(ref = 문자열, 여럿이면 "·"). 문법이 못 담으면 흉내 금지 → `연산 없음:` + 문법에 연산 추가 |
| 8 | 판례 | 그래도 a·b 가 갈린 곳은 심판이 정해 판례로 보고 → 진행자가 사용자 승인 후 지침으로 올림 |
